About

Web dev, design and the odd meme.

I’m a frontend developer from India, now living and working in Riyadh, Saudi Arabia. I started on GitHub in 2019, and my repositories tell the story: hand-built responsive sites, a hundred days of CSS challenges, React and Redux practice apps, then maps in Angular and a full TypeScript monorepo.

I like interfaces that feel effortless, and I like helping other developers get there faster. That’s why I write on LinkedIn and ran DailyDev, a 10-week series for busy JavaScript developers. Right now I’m learning system design.
